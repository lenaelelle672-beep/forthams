为固定资产管理系统的“系统运营中枢 / 基础资料 / 自定义字段”复刻一个高保真桌面后台页面。

参考产品图：
- IMAGE2：`frontend/public/mock/workspace-preview/asset-kit-v8/system-hub/subpages/master-data-subpage-05-custom-fields-v2.png`
- 当前 Stitch 候选：`frontend/public/mock/workspace-preview/asset-kit-v8/system-hub/subpages/stitch-master-data-subpage-05-custom-fields-v1.png`
- 目标：以 IMAGE2 v2 为主，候选稿只作为历史参考。不要生成通用配置模板。

核心原则：
- 这是固定资产管理系统的系统配置后台，不是营销页、不是 KPI 大屏、不是报表页。
- 顶部五个入口是独立业务视角：资产作业台、资产管理中枢、风险预警中心、数据分析中心、系统运营中枢；当前激活“系统运营中枢”。
- 左侧是系统运营中枢专用导航，展开“基础资料”，激活“自定义字段”。
- 顶部导航和左侧导航不放搜索；搜索必须出现在自定义字段专属页面的筛选区。

页面结构：
1. 顶部标题区
   - 标题：自定义字段治理台
   - 副标题：统一维护资产、待建资产池、CIP、盘点、维保和流程表单字段，控制类型、必填、字典、布局、导入导出、集成映射和历史影响。
   - 操作按钮：新建字段、保存草稿、提交校验、影响校验、导入字段。
   - 状态条：草稿已保存 10:08、历史影响待确认 1 项、发布影响 12 个表单、H5 布局待同步 2 项。

2. 左侧业务对象
   - 标题：业务对象。
   - 列表项：资产台账、待建资产池、CIP 项目、转固申请、盘点任务、维保工单、供应商档案。
   - 每项展示字段数量和状态，例如资产台账 48 字段、CIP 项目 16 字段、转固申请 12 字段。
   - 业务对象用于切换字段范围，不承担全局搜索。

3. 中央字段清单
   - 页面内搜索框 placeholder：搜索字段名称 / 编码 / 业务对象 / 字典 / 集成映射。
   - 筛选 chips：全部字段、必填、桌面显示、H5显示、待校验、停用。
   - 表格列：字段名称、字段编码、业务对象、字段类型、必填策略、字典来源、桌面布局、H5布局、集成映射、状态、操作。
   - 行数据示例：转固批次号 cip_cap_batch_no、设备序列号 device_serial_no、MAC地址 mac_address、保修到期日 warranty_expire_date、发票号 invoice_no。
   - 操作：编辑、影响、停用。

4. 底部预览与影响区
   - 四个紧凑面板：桌面表单预览、钉钉H5预览、导入导出模板、字段影响矩阵。
   - 预览必须体现同一字段在桌面和 H5 中的位置。
   - 导入导出模板必须体现列名、字段编码、必填、示例值。
   - 影响矩阵必须体现 CIP 转固表单、资产卡片、导入模板、ERP 映射、历史实例等影响对象。

5. 右侧字段属性
   - 标题：字段属性。
   - 当前字段：转固批次号，字段编码：cip_cap_batch_no，字段类型：文本 / 唯一编码。
   - 字段：字段名称、字段编码、业务对象、字段类型、默认值、必填策略、字典来源、校验表达式、桌面布局绑定、H5布局绑定、导入导出绑定、集成映射、权限策略、历史影响、审计策略。
   - 风险提示：发布后历史实例保持原字段版本、ERP 回执冻结不允许无痕修改、H5 与桌面布局需同步。
   - 发布门禁：编码唯一、类型合法、必填策略、字典来源、布局绑定、导入导出、集成映射、历史影响。

视觉要求：
- 现代中文 B2B 后台，高保真、密度高但可读。
- 白色和极浅灰面板，1px 细分割线，按钮和卡片圆角不超过 8px。
- 色彩克制：蓝色用于主操作，绿色用于已发布/通过，橙色用于待校验/历史影响，红色只用于错误。
- 表格和右侧编辑器是主导，不要把页面做成摘要卡堆叠或图表大屏。
- 不要渐变大背景、装饰球、插画 Hero、营销文案、深色模糊背景。

交互暗示：
- 用户可以新建字段、编辑字段属性、查看桌面/H5预览、执行影响校验、保存草稿、提交校验。
- 搜索和筛选只影响自定义字段表格。
- 字段发布必须保留历史实例版本，不能无痕修改已使用字段。
- 点击“查看审计”后必须在当前页展开字段引用审计记录，不允许打开通用占位弹窗；审计记录至少包含字段引用、字段集版本、表单布局、导入导出、集成映射和历史实例。

## 硬性复刻要求
- 顶部业务视角和左侧导航不得放搜索框；搜索/筛选只能出现在当前专属页面内容区。
- 页面必须包含可真人模拟的保存草稿动作，并在操作反馈区显示保存结果。
- 页面必须包含可真人模拟的提交校验/发布复核动作，并在操作反馈区显示校验或复核结果。
- 新建、编辑、搜索、详情预览、保存、提交必须围绕当前业务对象完成，不得复用通用占位模板。
- “查看审计”必须在当前自定义字段页面生成字段引用、字段集版本、表单布局、导入导出、集成映射和历史实例审计链路。
