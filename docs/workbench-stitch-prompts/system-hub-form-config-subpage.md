[Context]
UNIVIEW 固定资产管理系统，System Operation Hub / 系统运营中枢。请复刻 IMAGE2 产品图 `frontend/public/mock/workspace-preview/asset-kit-v8/system-hub/subpages/flow-platform-subpage-03-form-config-v2.png` 的后台表单配置页。v2 是准绳，v1 仅作废弃参考。页面属于固定资产系统，不是制造大屏、不是营销页。

目标：生成高保真桌面后台页面，用户可以在同一页完成表单新建、字段维护、桌面布局、钉钉 H5 布局、保存草稿、提交校验。

[Layout]
Desktop 1586x992。顶部深色导航包含“固定资产工作台 / 资产全景视图 / 大屏态势 / 流程协同 / 系统运营中枢”，必须只有“系统运营中枢”高亮。顶部导航和左侧导航都不要出现任何全局搜索框、搜索图标或搜索输入；搜索只能出现在当前页面内容区的表单对象/字段筛选栏。左侧为系统运营中枢导航，流程平台展开，表单配置高亮。

主区标题“表单字段与双端布局配置”，顶部操作条包含：新建表单、新增字段、保存草稿、提交校验、H5 预览。标题下显示操作反馈条“表单草稿已保存 / 表单校验已提交”。

核心区域三栏：
左栏：表单对象列表，包含“待建资产入账表单 / CIP 转固验收表单 / 资产处置赔偿表单 / 新建表单草稿”，显示业务对象、版本、状态。
中栏：字段配置与表单设计画布。上方是字段摘要和字段表格，列包含字段名称、编码、类型、来源、必填、桌面分组、H5 可见。下方并列两个预览：桌面表单画布和钉钉 H5 表单预览。桌面画布展示基础信息、资产信息、附件信息分组；H5 预览展示紧凑字段、附件和审批按钮。
右栏：字段属性配置，包含字段名称、字段编码、字段类型、来源、必填开关、桌面分组、H5 显示、校验规则、保存字段按钮。

[Components]
企业后台风格：白色和浅蓝灰面板、深色顶部栏、蓝色主按钮、细边框、8px 以内圆角、紧凑表格、状态 pill。不要做 KPI 大屏，不要大卡片堆砌。

易用性要求：
- 表单对象、字段列表、桌面/H5 预览、字段属性同屏联动。
- 一套字段定义，两套布局，文案明确显示“桌面布局 / 钉钉 H5 布局”。
- 发布门禁 checklist 显示字段编码、必填校验、H5 可见、存储映射是否通过。

## 硬性复刻要求
- 顶部业务视角和左侧导航不得放搜索框；搜索/筛选只能出现在当前专属页面内容区。
- 页面必须包含可真人模拟的保存草稿动作，并在操作反馈区显示保存结果。
- 页面必须包含可真人模拟的提交校验/发布复核动作，并在操作反馈区显示校验或复核结果。
- 新建、编辑、搜索、详情预览、保存、提交必须围绕当前业务对象完成，不得复用通用占位模板。
