为固定资产管理系统的“系统运营中枢 / 基础资料 / 自定义字段集”生成一个高保真桌面后台页面，按 IMAGE2 v2 产品图复刻。

页面定位：自定义字段集编排台。它不是泛用配置模板，而是把资产卡片、CIP 转固、服务器、笔记本、盘点、维保和流程表单的字段组合成可复用字段集，并统一维护桌面页面、钉钉 H5 表单、导入模板、集成映射和版本发布。

全局结构：
- 顶部横向导航展示：资产作业台、资产管理中枢、风险预警中心、数据分析中心、系统运营中枢；系统运营中枢高亮。
- 左侧为系统运营中枢导航，不出现全局搜索；基础资料分组展开，自定义字段集高亮。
- 主内容标题为“自定义字段集编排台”，副标题说明“按资产卡片、CIP 转固、服务器、笔记本、盘点、维保和流程表单组合字段，统一维护桌面/H5/导入模板套用和版本发布。”

核心操作：
- 标题右侧按钮：新建字段集、保存草稿、提交校验、套用预览、发布版本、导入字段集。
- 标题下方反馈条展示：草稿已保存 10:22、待发布版本 3、影响页面 12、H5 套用待同步 2。

页面主体：
- 左侧内嵌面板“业务对象/字段集方案”，列出资产卡片基础字段集、CIP转固字段集、服务器字段集、笔记本字段集、盘点任务字段集、维保工单字段集；每项显示字段数、版本和状态，CIP转固字段集选中。
- 中心顶部为页面内搜索和筛选，不要放到导航上。搜索占位：“搜索字段集名称 / 编码 / 业务对象 / 字段”。筛选 chip：全部字段集、资产卡片、CIP、IT设备、流程表单、待校验、已发布。
- 中心主表格列：字段集名称、编码、业务对象、字段数、版本、桌面页面、H5表单、导入模板、状态、操作。
- 示例行：CIP转固字段集、服务器字段集、笔记本责任字段集、盘点差异字段集、维保工单字段集；操作含编辑、预览、发布。
- 下方工作区“字段组成排序”，用表格表达可拖拽排序和字段策略，字段包括转固批次号、项目编号、资产小类、供应商、发票号、ERP回执号。列包含排序、字段名称、字段类型、必填、桌面显示、H5显示、导入模板、校验规则。
- 工作区右侧或下方展示“桌面套用预览”“H5套用预览”和“版本影响矩阵”，矩阵覆盖资产卡片、CIP转固、导入模板、历史实例。
- 右侧固定属性面板“字段集属性”，字段包括名称、编码、业务对象、当前版本、字段组成、排序策略、桌面布局绑定、H5布局绑定、导入导出模板、集成映射、权限策略、历史影响、审计策略。
- 属性面板下方有橙色风险提示：发布后生成字段集版本快照；已发布版本不能无痕改字段顺序；H5/桌面/导入模板需同步。
- 最下方“发布门禁”展示编码唯一、字段存在、排序合法、必填策略、布局绑定、H5套用、导入导出、历史影响、权限审计，显示 8/9 通过，历史影响待处理。
- 点击“查看审计”后必须在当前页展开字段集引用审计记录，不允许打开通用占位弹窗；审计记录至少包含字段引用、字段集版本、表单布局、导入导出、集成映射和历史实例。

视觉要求：
- 现代中文 B2B 后台，白色面板、细分割线、克制蓝色、绿色、青色、橙色状态。
- 表格为主导，信息密度高但可读，重点突出字段组成、排序、版本影响和发布门禁。
- 卡片圆角不超过 8px，不要装饰球，不要暗色大屏风格，不做 KPI 大屏。
- 输出 16:10 桌面画面，适合 Vite React 实现。

## 硬性复刻要求
- 顶部业务视角和左侧导航不得放搜索框；搜索/筛选只能出现在当前专属页面内容区。
- 页面必须包含可真人模拟的保存草稿动作，并在操作反馈区显示保存结果。
- 页面必须包含可真人模拟的提交校验/发布复核动作，并在操作反馈区显示校验或复核结果。
- 新建、编辑、搜索、详情预览、保存、提交必须围绕当前业务对象完成，不得复用通用占位模板。
- “查看审计”必须在当前自定义字段集页面生成字段引用、字段集版本、表单布局、导入导出、集成映射和历史实例审计链路。
