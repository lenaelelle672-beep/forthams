UNIVIEW 固定资产管理系统，System Operation Hub / 系统运营中枢。请复刻 IMAGE2 产品图 `flow-platform-subpage-04-form-storage-v2.png` 的表单存储页。页面是固定资产后台配置，不是报表大屏。

目标：生成高保真桌面后台页面，用户能维护表单定义版本、字段存储映射、表单实例快照、附件索引、归档目标、查询审计，并能新建存储方案、新增映射、归档预演、保存草稿、提交校验。

[Layout]
Desktop 1586x992。顶部深色导航含“固定资产工作台 / 资产全景视图 / 大屏态势 / 流程协同 / 系统运营中枢”，系统运营中枢高亮。顶部导航和左侧导航都不要搜索图标、搜索按钮、搜索输入框。左侧系统配置导航展开流程平台，表单存储高亮。

主区标题“表单存储映射与归档策略”，操作条包含：新建存储方案、新增映射、保存草稿、归档预演、提交校验。顶部显示绿色反馈条“归档预演已完成 · 48 条 CIP 转固实例可归档，附件索引与审计链路通过”。

核心区域三栏：
左栏：表单对象列表，包含“CIP 转固验收表单 / 待建资产入账表单 / 采购变更审批表 / 资产移交表单”，显示编码、版本、状态。只在这个页面内容区放一个本页搜索框，占位“搜索表单 / 编码 / 业务对象”。
中栏：字段存储映射工作台。上方是摘要卡：存储方案、已启用、脱敏字段、待补映射。中部是字段存储映射表格，列包含字段名称、字段编码、类型、存储表、存储字段、索引、脱敏、归档策略、状态、操作；选中“转固金额 cap_amount”，ERP 凭证号显示橙色待确认。下方是存储模型预览，展示 AMS_FORM_INSTANCE、AMS_FORM_FIELD_VALUE、AMS_ATTACHMENT、AMS_CIP_CAPITALIZATION 四个表关系，再展示归档预演结果：48 条待归档实例、126 个附件索引、8 年保留、资产卡片关联已建立、ERP 回执字段待确认。
右栏：映射属性配置，当前字段为“转固金额 cap_amount”，包含表单版本、存储表、存储字段、字段类型、索引策略、加密/脱敏、归档周期、数据保留、审计要求；底部发布校验 5/6，ERP 回执字段为橙色待确认。

企业后台质感，表格为主，信息密度高。使用浅蓝灰背景、白色面板、细分割线、蓝色主按钮、橙色预警、绿色通过态。不要使用营销图、人物、制造产线照片。

易用性要求：
- 表单对象、字段存储映射、存储模型预览、归档预演、属性配置、发布校验同屏。
- 归档预演必须清楚显示“48 条待归档实例 / 126 个附件索引 / 8 年保留 / 资产卡片关联 / ERP 回执字段待确认”。
- 发布校验 checklist 覆盖字段映射、类型兼容、索引策略、敏感字段脱敏、附件归档、ERP 回执字段。

## 硬性复刻要求
- 顶部业务视角和左侧导航不得放搜索框；搜索/筛选只能出现在当前专属页面内容区。
- 页面必须包含可真人模拟的保存草稿动作，并在操作反馈区显示保存结果。
- 页面必须包含可真人模拟的提交校验/发布复核动作，并在操作反馈区显示校验或复核结果。
- 新建、编辑、搜索、详情预览、保存、提交必须围绕当前业务对象完成，不得复用通用占位模板。
