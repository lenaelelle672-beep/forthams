[Context]
UNIVIEW 固定资产管理系统，System Operation Hub / 系统运营中枢。请忽略任何旧的“智能制造总览”或制造管控语义，本屏是固定资产系统后台配置页。目标是复刻 IMAGE2 产品图 `flow-platform-subpage-02-flow-designer-v2.png` 的流程设计器体验。v2 是准绳，v1 仅作废弃参考。

设计准则：后台操作方便快捷。流程设计器不是小表单，也不是普通配置页，必须是大画布建模工作台。新建流程图后，用户要能在同一屏完成拖拽环节节点、连线、配置节点信息、保存节点、保存草稿、提交校验、发布流程。

[Layout]
Desktop 1586x992。顶部深色导航，包含“资产运营总览 / 数据监控中心 / 资产运维中心 / 风险预警中心 / 系统运营中枢”，系统运营中枢高亮。顶部导航、页面头部、左侧导航、左侧系统定位区都不要出现任何全局搜索框、搜索图标按钮或“搜索系统配置”输入框；搜索只能出现在需要检索数据的专属页面内容区，本流程设计器页面不需要导航搜索。左侧为系统配置模式，流程平台展开，流程设计器高亮。

主区域顶部标题“流程设计器”，工具条包含：新建流程图、保存草稿、提交校验、撤销、重做、排列主路径、展开模板库。工具条下方显示操作反馈“新建流程图草稿已创建 / 节点配置已保存”。

核心区域是三栏建模工作室，画布优先：
左栏：节点库，可拖拽节点模板，宽度控制在 180-220px，包含开始节点、审批节点、条件分支、ERP 推送、EHR 同步、归档节点、通知节点。每个节点卡片有清晰图标、拖拽手柄和简短说明。
中栏：超大流程画布，占主工作区最大面积，不能小于页面内容宽度的 62%、内容高度的 70%。画布带泳道、网格、连线、缩放工具、自动布局入口。显示 CIP 资本化补充流程图：开始 -> 发起人提交 -> CIP 专员审核 -> 资产会计审核 -> ERP 回执归档 -> 完成。画布中有一个审批节点被选中，显示蓝色选中边框、连接点、拖拽手柄，旁边有添加节点虚线框“拖拽节点到此处”。
右栏：节点属性配置，固定在右侧，宽度 300-360px，不能挤压成窄栏。包含节点名称、节点类型、处理人规则、跳过重复处理人、离职交接规则、表单字段、SLA 时限、外部系统推送、校验清单、保存节点按钮。属性区要像真实可编辑面板，不要只做说明文字。

底部显示操作日志，记录“节点已放入画布 / 节点配置已保存 / 流程草稿已保存”。

[Components]
企业级后台高保真，白色和浅蓝灰面板、深色顶部栏、蓝色主按钮、状态 icon、8px 以内圆角、精细边框。不要做营销页，不要做空白画布，不要使用大 KPI 卡，不要出现人物或制造产线照片。

必须体现易用性：
- 节点库、画布、属性配置同屏，少跳转。
- 画布空间最大化，右侧属性足够宽，左侧系统导航可保持紧凑，避免抢占建模面积。
- 常用动作固定可见，日志即时反馈。
- 校验清单告诉用户还差什么。

## 硬性复刻要求
- 顶部业务视角和左侧导航不得放搜索框；搜索/筛选只能出现在当前专属页面内容区。
- 页面必须包含可真人模拟的保存草稿动作，并在操作反馈区显示保存结果。
- 页面必须包含可真人模拟的提交校验/发布复核动作，并在操作反馈区显示校验或复核结果。
- 新建、编辑、搜索、详情预览、保存、提交必须围绕当前业务对象完成，不得复用通用占位模板。
