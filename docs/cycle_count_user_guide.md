# 循环盘点功能使用指南

## 功能概述

循环盘点是根据资产 ABC 分类和盘点频率，自动生成盘点任务的功能。相比全盘点，循环盘点可以：
- 减少盘点工作量
- 提高盘点效率
- 降低盘点成本
- 聚焦高价值资产

## 盘点规则设置

### 1. 创建循环盘点规则

1. 进入 **循环盘点管理** 页面（路径：`/inventory/cycle-count`）
2. 点击 **新增规则** 按钮
3. 填写规则信息：
   - **分类类型**：选择 A/B/C
   - **盘点频率**：选择月度/季度/年度
   - **分类 ID**：选择适用的资产分类（可多选，JSON 格式）
   - **最小值**：设置价值区间下限（左闭区间）
   - **最大值**：设置价值区间上限（右开区间）
4. 点击 **保存**

### 2. 盘点频率说明

| 分类类型 | 盘点频率 | 自动触发时间 | 说明 |
|---------|---------|-------------|------|
| A 类 | 月度 | 每月 1 日凌晨 2 点 | 高价值资产，高频盘点 |
| B 类 | 季度 | 每季度首月 1 日凌晨 3 点 | 中价值资产，中频盘点 |
| C 类 | 年度 | 每年 1 月 1 日凌晨 4 点 | 低价值资产，低频盘点 |

### 3. 分类规则与 ABC 分类的集成

循环盘点规则基于资产的 ABC 分类进行匹配：
- 系统会先根据循环盘点规则自动更新资产的 ABC 分类
- 然后根据 ABC 分类（A/B/C）筛选资产生成盘点任务

## 定时任务配置

### 系统自动触发

系统已配置定时任务，自动按规则生成盘点任务：
- A 类：每月 1 日凌晨 2 点
- B 类：每季度首月 1 日凌晨 3 点
- C 类：每年 1 月 1 日凌晨 4 点

### 定时任务配置（可选）

如需修改定时任务时间，请联系系统管理员修改 `CycleCountService.java` 中的 `@Scheduled` 注解配置。

## 手动触发盘点

### 操作步骤

1. 进入 **循环盘点管理** 页面
2. 在规则列表中找到需要触发的规则
3. 点击 **手动触发** 按钮
4. 确认操作

### 注意事项

- 手动触发会立即生成盘点任务，不受定时任务时间限制
- 同一规则在同一个月内只会生成一次任务
- 手动触发的任务任务号格式：`CC-YYYYMM-CLASSIFICATION-RULEID`

## 盘点任务执行

### 1. 查看待执行任务

1. 进入 **盘点任务** 页面（路径：`/inventory`）
2. 筛选任务类型为 **循环盘点**（`inventory_type = 'CYCLE_COUNT'`）
3. 查看任务状态为 **草稿**（`status = 'DRAFT'`）的任务

### 2. 开始盘点任务

1. 选择一个草稿状态的盘点任务
2. 点击 **开始盘点** 按钮
3. 系统自动填充符合规则的资产列表（基于循环盘点规则筛选）

### 3. 扫描录入

#### 方式一：RFID 扫描

1. 使用 RFID 扫描枪扫描资产标签
2. 系统自动记录扫描时间和实际位置
3. 资产状态更新为 **已盘点**（`status = 'COUNTED'`）

#### 方式二：手动录入

1. 在盘点明细列表中找到未盘点资产
2. 输入实际位置和扫描时间
3. 点击 **保存**

### 4. 完成盘点

1. 确认所有资产都已盘点完成
2. 点击 **完成盘点** 按钮
3. 系统自动计算差异：
   - **盘盈**：实际数量 > 预期数量
   - **盘亏**：实际数量 < 预期数量
   - **正常**：实际数量 = 预期数量

## 差异处理

### 1. 查看差异汇总

盘点完成后，系统自动生成差异汇总：
- 盘盈数量
- 盘亏数量
- 损坏数量
- 总差异金额

### 2. 提交审批

1. 点击 **提交审批** 按钮
2. 填写备注说明
3. 系统创建审批流程

### 3. 自动调账

审批通过后，系统可以自动处理差异：
- **盘盈**：创建新资产记录
- **盘亏**：标记资产为丢失
- **损坏**：标记资产为损坏

## ABC 分类集成说明

### 自动填充资产列表

循环盘点任务生成时，会自动根据以下条件筛选资产：
1. **ABC 分类匹配**：`asset.abc_classification = rule.classification`
2. **分类 ID 匹配**：`asset.category_id IN rule.categoryIds`（JSON 解析）
3. **价值区间匹配**：`asset.original_value >= rule.min_value AND asset.original_value < rule.max_value`
4. **租户隔离**：`asset.tenant_id = rule.tenant_id`

### 资产创建/编辑时自动分类

当创建或编辑资产时，系统会自动根据循环盘点规则更新 ABC 分类：
- 分类失败不影响资产保存（降级策略）
- 系统记录警告日志
- 建议定期执行批量重新分类

### 批量重新分类

如需重新计算所有资产的 ABC 分类：
1. 进入 **ABC 分类管理** 页面（路径：`/inventory/abc-classification`）
2. 点击 **批量重新分类** 按钮
3. 确认操作

## 常见问题

### Q1：为什么生成的盘点任务没有自动填充资产？

**A**：可能原因：
- 没有匹配循环盘点规则的资产
- 规则配置的价值区间或分类 ID 不正确
- 资产的 ABC 分类字段为空

**解决方法**：
1. 检查循环盘点规则配置
2. 执行批量重新分类操作
3. 查看后端日志中的警告信息

### Q2：如何查看本月已生成的盘点任务？

**A**：
1. 进入 **盘点任务** 页面
2. 筛选任务类型为 **循环盘点**
3. 查看任务编号格式：`CC-YYYYMM-CLASSIFICATION-RULEID`
4. 任务编号中的 `YYYYMM` 表示月份

### Q3：手动触发盘点会重复生成任务吗？

**A**：不会。系统会检查本月是否已生成过相同分类的盘点任务，如果已存在则跳过生成。

### Q4：盘点任务的有效期是多长？

**A**：
- 月度盘点任务：30 天
- 季度盘点任务：90 天
- 年度盘点任务：365 天

任务到期后需要重新生成或手动延长有效期。

### Q5：如何修改盘点任务的有效期？

**A**：请联系系统管理员修改 `CycleCountService.getDurationDays()` 方法的返回值。

### Q6：盘点任务支持跨部门盘点吗？

**A**：支持。循环盘点任务可以根据循环盘点规则的分类 ID 筛选不同部门的资产。

### Q7：盘点任务如何关联到审批流程？

**A**：盘点任务完成后，可以提交审批流程。审批通过后，系统可以自动处理盘盈、盘亏、损坏等差异。

## 权限要求

使用循环盘点功能需要以下权限：
- `cycle-count:query`：查看循环盘点规则
- `cycle-count:create`：创建循环盘点规则
- `cycle-count:update`：编辑循环盘点规则
- `cycle-count:delete`：删除循环盘点规则
- `cycle-count:trigger`：手动触发生成盘点任务

## 技术实现

### 任务生成流程

1. 定时任务触发（或手动触发）
2. 遍历所有启用的循环盘点规则
3. 检查本月是否已生成过任务（幂等性）
4. 查询符合条件的资产（基于 ABC 分类、分类 ID、价值区间）
5. 创建盘点任务（`inventory_task` 表）
6. 批量创建盘点明细（`inventory_detail` 表）

### 资产筛选逻辑

```java
// 匹配 ABC 分类
wrapper.eq(Asset::getAbcClassification, rule.getClassification());

// 匹配分类 ID
if (rule.getCategoryIds() != null) {
    List<Long> categoryIds = objectMapper.readValue(rule.getCategoryIds());
    wrapper.in(Asset::getCategoryId, categoryIds);
}

// 匹配价值区间（左闭右开）
if (rule.getMinValue() != null) {
    wrapper.ge(Asset::getOriginalValue, rule.getMinValue());
}
if (rule.getMaxValue() != null) {
    wrapper.le(Asset::getOriginalValue, rule.getMaxValue());
}
```

### 多租户隔离

所有数据库操作都包含 `tenant_id` 字段，确保租户数据隔离。

## 最佳实践

### 1. 规则配置建议

- **A 类规则**：设置较高的最小值（如 10000），确保只包含高价值资产
- **B 类规则**：设置中等价值区间（如 5000-10000）
- **C 类规则**：设置较低的最大值（如 5000），包含大部分低价值资产

### 2. 盘点频率优化

- 根据资产重要性调整盘点频率
- 高价值资产增加盘点频率
- 低价值资产减少盘点频率

### 3. 定期检查

- 每月检查盘点任务执行情况
- 定期检查 ABC 分类准确性
- 及时处理盘点差异

### 4. 数据备份

- 盘点前备份重要数据
- 定期备份盘点任务和明细
- 保留历史盘点记录
