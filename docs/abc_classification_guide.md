# ABC 分类用户操作手册

## 功能说明

ABC 分类是一种基于资产价值的分类方法，将资产按重要性分为三个等级：
- **A 类（高价值资产）**：原值最高的约 20% 资产，累计价值占比约 80%，需**月度盘点**
- **B 类（重要资产）**：原值次高的约 30% 资产，累计价值占比约 15%，需**季度盘点**
- **C 类（低价值资产）**：剩余约 50% 资产，累计价值占比约 5%，需**年度盘点**
- **CATEGORY（未分类）**：未匹配任何分类规则的资产，需要检查规则配置

系统会根据资产原值（`originalValue`）和分类规则自动分配 ABC 分类。

## 分类规则配置

### 1. 访问循环盘点规则配置页面

- 路径：`/inventory/cycle-count`
- 权限要求：`cyclecount:query`

### 2. 创建或编辑分类规则

在规则配置页面，可以设置以下参数：

| 参数 | 说明 | 示例 |
|------|------|------|
| ABC 分类 | 资产分类等级 | A / B / C |
| 盘点频率 | 该类资产的盘点周期 | 月度 / 季度 / 年度 |
| 最小价值 | 资产原值的下限（元） | 10000 |
| 最大价值 | 资产原值的上限（元） | 100000 |
| 适用资产分类 | 限制规则的适用范围（JSON 数组） | [1, 2, 3] |

**价值区间规则**：系统使用**左闭右开区间**匹配，即 `minValue <= originalValue < maxValue`。
- 如果只设置最小值，则匹配所有 `originalValue >= minValue` 的资产
- 如果只设置最大值，则匹配所有 `originalValue < maxValue` 的资产
- 如果都设置，则匹配在区间内的资产

### 3. 规则示例

**A 类规则**（高价值资产，月度盘点）：
- 分类：A
- 频率：MONTHLY（月度）
- 最小价值：10000
- 最大价值：100000
- 适用分类：留空（适用于所有分类）

**B 类规则**（重要资产，季度盘点）：
- 分类：B
- 频率：QUARTERLY（季度）
- 最小价值：1000
- 最大价值：9999.99
- 适用分类：留空（适用于所有分类）

**C 类规则**（低价值资产，年度盘点）：
- 分类：C
- 频率：YEARLY（年度）
- 最小价值：0
- 最大价值：999.99
- 适用分类：留空（适用于所有分类）

## 批量重新分类

### 1. 访问 ABC 分类管理页面

- 路径：`/inventory/abc-classification`
- 权限要求：`abc:query`、`abc:reclassify`

### 2. 查看分类统计

页面顶部展示四个统计卡片：
- A 类资产数量和总价值
- B 类资产数量和总价值
- C 类资产数量和总价值
- 未分类资产（CATEGORY）数量和总价值

### 3. 执行批量重新分类

1. 点击右上角「批量重新分类」按钮
2. 在确认对话框中点击「确认」
3. 系统会遍历所有资产，根据当前规则重新计算 ABC 分类
4. 操作完成后会显示成功/失败统计

**注意事项**：
- 批量分类可能需要较长时间，取决于资产数量
- 分类失败不影响资产保存，失败的资产会保留原分类或设为 CATEGORY
- 建议在业务低峰期执行批量分类

### 4. 按分类 ID 批量分类（高级功能）

如果只想重新分类特定分类的资产，可以使用 API：
```
POST /api/abc/reclassify/by-category
Body: [1, 2, 3]  // 分类 ID 列表
```

## 分类统计查看

在 ABC 分类管理页面，可以查看：
- 各类资产的数量和总价值
- 资产列表（包含资产编号、名称、分类、ABC 分类、原值）
- 分类标签颜色：A 类（红色）、B 类（蓝色）、C 类（绿色）、未分类（灰色）

## 导出报告

### 1. 导出 ABC 分类报告

在 ABC 分类管理页面，点击「导出报告」按钮，系统会生成 Excel 文件，包含：

**统计工作表**：
- 各类资产的数量和总价值
- 总计汇总

**资产列表工作表**：
- 资产编号
- 资产名称
- ABC 分类
- 原值
- 分类

### 2. 文件命名规则

文件名格式：`ABC分类报告_YYYY-MM-DD.xlsx`

## 常见问题解答

### Q1：为什么某些资产显示为「未分类（CATEGORY）」？

**A**：可能是以下原因：
1. 资产原值（`originalValue`）为空或 0
2. 资产的原值不在任何规则的价值区间内
3. 资产的分类不在规则的适用范围内

**解决方法**：
1. 检查规则配置是否覆盖了所有价值区间
2. 确认资产原值已正确填写
3. 执行批量重新分类

### Q2：如何修改资产的 ABC 分类？

**A**：系统不支持手动修改 ABC 分类，只能通过以下方式更新：
1. 修改循环盘点规则配置
2. 执行批量重新分类
3. 修改资产的原值或分类字段，系统会自动重新分类

### Q3：批量分类失败了怎么办？

**A**：
1. 检查后端日志，查看失败原因
2. 确认循环盘点规则配置正确
3. 确认所有资产的 `originalValue` 和 `categoryId` 字段已填写
4. 重试批量分类操作

### Q4：如何新增循环盘点规则？

**A**：
1. 访问 `/inventory/cycle-count` 页面
2. 点击「新增规则」按钮
3. 填写规则参数（分类、频率、价值区间、适用分类）
4. 点击「确定」保存
5. 保存后立即生效，下次批量分类时会使用新规则

### Q5：分类规则之间的优先级如何？

**A**：
- 系统按规则顺序遍历匹配，找到第一个匹配的规则即停止
- 建议将最严格的规则（如 A 类）放在前面
- 如果多个规则同时匹配一个资产，使用最先匹配的规则

### Q6：ABC 分类与循环盘点任务的关系是什么？

**A**：
- 系统根据 ABC 分类自动生成循环盘点任务：
  - A 类：每月 1 日凌晨 2 点自动生成
  - B 类：每季度首月 1 日凌晨 3 点自动生成
  - C 类：每年 1 月 1 日凌晨 4 点自动生成
- 可以在循环盘点配置页面手动触发盘点任务生成
- 生成的盘点任务会自动填充对应分类的资产列表

### Q7：如何验证分类规则是否正确？

**A**：
1. 在 ABC 分类管理页面查看统计分布
2. 检查 A、B、C 类资产的数量比例是否合理（建议约为 20% : 30% : 50%）
3. 抽查部分资产的原值和分类是否匹配规则
4. 导出报告进行人工审核

## 技术说明

### 分类算法

系统使用**价值区间匹配**算法：

1. 查询所有启用的循环盘点规则（`deleted=0`）
2. 对每个资产，遍历规则进行匹配：
   - 检查价值区间：`minValue <= originalValue < maxValue`（左闭右开）
   - 检查分类 ID：如果规则指定了 `categoryIds`，资产分类必须在列表中
3. 匹配成功则更新资产的 `abc_classification` 字段
4. 未匹配任何规则的资产设为 `CATEGORY`

### 降级策略

- **JSON 解析失败**：如果 `categoryIds` JSON 格式错误，记录警告日志并跳过该规则
- **分类失败**：资产创建/编辑时分类失败不影响保存，资产保留原分类或默认为 C
- **批量操作失败**：批量分类时单条资产失败不影响其他资产，记录失败数量

### 性能优化

- 批量分类使用 MyBatis-Plus `saveBatch`，每批 500 条记录
- 循环盘点任务生成时，批量创建 `InventoryDetail`，每批 500 条
- 数据库索引：`idx_asset_abc_classification` 提升查询性能
